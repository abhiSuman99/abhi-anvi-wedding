# Wedding photos

Add the wedding photographs here. Recommended filenames:

- `couple-hero.jpg` — wide cover photograph
- `couple-portrait.jpg` — vertical couple portrait
- `groom.jpg` — groom portrait
- `bride.jpg` — bride portrait
- `gallery-01.jpg`, `gallery-02.jpg`, etc. — gallery photographs

For a fast website, export JPG or WebP files around 1600–2200 pixels wide and preferably below 1 MB each.

Full-resolution JPG files in this folder remain local and are intentionally excluded from Git. Optimized website copies are stored in `optimized/` and are committed.
